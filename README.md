# سوپرمارکت صدرا — نسخه اولیه

این پروژه یک نمونه اولیه چندسکویی با Expo / React Native است و برای اجرای آزمایشی روی وب و اندروید آماده شده است.

## اجرا
1. Node.js نسخه LTS را نصب کنید.
2. در پوشه پروژه اجرا کنید:
   ```bash
   npm install
   npx expo start
   ```
3. برای وب:
   ```bash
   npx expo start --web
   ```
4. برای اندروید، برنامه Expo Go را روی گوشی نصب کنید و QR نمایش‌داده‌شده در ترمینال/مرورگر را اسکن کنید.

## امکانات نمونه اولیه
- فهرست نمونه محصولات و جستجو
- سبد خرید و محاسبه هزینه ارسال
- ارسال رایگان برای خریدهای **بیشتر از ۵۰۰٬۰۰۰ تومان**
- محاسبه هدیه ۳٪ پس از تغییر وضعیت سفارش به «تحویل شد»
- صفحه کیف پول، سفارش‌ها و مدیریت آزمایشی قیمت/وضعیت سفارش
- اطلاعات تماس و آدرس فروشگاه

## موارد لازم پیش از انتشار عمومی
این نسخه **دموی محلی** است؛ اطلاعات آن بین دستگاه‌های مختلف همگام‌سازی نمی‌شود و احراز هویت واقعی ندارد. برای انتشار عملیاتی باید:
- پایگاه داده و API مرکزی (مثلاً Supabase یا Firebase) متصل شود تا قیمت‌ها و سفارش‌ها بین وب و همه گوشی‌ها زنده همگام شوند.
- ورود با شماره موبایل و سطح دسترسی امن مدیر پیاده‌سازی شود.
- قانون کیف پول با تاریخ آزادسازی ماهانه، دفترکل تراکنش و جلوگیری از اعتباردهی تکراری در سمت سرور اجرا شود.
- درگاه پرداخت، محدوده/هزینه پیک، آدرس‌ها و سیاست لغو سفارش تعیین شود.
- نسخه نهایی Android با EAS Build یا Android Studio ساخته و وب روی دامنه منتشر شود.
- QR واقعی فقط پس از انتشار لینک دانلود/صفحه نصب ساخته شود.

## قوانین تنظیم‌شده
- هدیه: ۳٪ از ارزش کالاها، فقط پس از تحویل موفق سفارش.
- ارسال رایگان: طبق درخواست، خرید بالای ۵۰۰٬۰۰۰ تومان. در این نمونه شرط به‌صورت `>` است.
- واحد قیمت: تومان.


## اتصال پایگاه داده آنلاین
- فایل `SETUP_SUPABASE_FA.md` را بخوانید.
- ساختار SQL در `supabase/schema.sql` قرار دارد.
- تنظیمات کلاینت در `.env.example` است.
- `src/data.ts` دریافت محصولات و اشتراک تغییرات زنده را فراهم می‌کند.
- بدون URL و کلید Supabase، برنامه در حالت نمایشی باقی می‌ماند.
